How to change ChannelFence's language

Updated November 2, 2026 · For ChannelFence 0.2.8

ChannelFence follows Chrome's interface language by default. You can also choose a language in settings for the popup, settings pages, and ChannelFence's blocking controls on YouTube.

Choose a language in settings

  1. Select the ChannelFence icon in Chrome's extensions area.
  2. Select Manage block list at the bottom of the popup to open the full settings page.
  3. Use the Language selector at the top of settings and choose your preferred language.

Your choice is saved automatically on this device. Open ChannelFence pages and controls update to use it; there is no separate Save button.

If the current interface is unfamiliar, the language selector is the first setting. Its language choices use their own names, such as 日本語, Português (Brasil), and العربية.

Which languages are available?

Version 0.2.8 includes 18 interface options: English, Korean, Japanese, Brazilian Portuguese, Russian, Spanish, French, German, Simplified Chinese, Traditional Chinese, Hindi, Indonesian, Bengali, Turkish, Vietnamese, Arabic, Italian, and Dutch.

Arabic uses right-to-left layouts on extension pages and ChannelFence controls. Creator names, handles, channel URLs, and your block-list backups are preserved rather than translated.

Return to automatic language selection

Choose Automatic (browser language) in the same selector. ChannelFence will use Chrome's interface language again, with English as the fallback when a matching translation is unavailable.

A manual choice stays selected until you change it, even if you use a different language on YouTube. The preference is stored locally, so choose it separately on another device or Chrome profile.

Chrome, YouTube, and this website have separate language settings

Changing ChannelFence's language does not change YouTube's menus, video titles, or language setting. You can use ChannelFence in one language and YouTube in another. Chrome also chooses the extension name and description shown in its own extension manager independently of ChannelFence's manual selection.

This website is currently in English. Your browser's page translation feature can translate these guides; the extension's language selector does not translate the website.

Does changing language affect blocking?

Your block list and feed preferences stay the same. Translations are included with the extension, so choosing a language does not send your settings or creator names to a translation service.

If a label is unclear or a control does not work on a particular YouTube layout, report it with your ChannelFence version, chosen language, YouTube language, and the page where it happened. YouTube changes its layouts, so a useful report describes the affected control as well as the translation.

Choose the language that works for you.
ChannelFence is free, open source, and keeps your preferences on your device.
