# Campaign attribution links

Use one link per asset. Do not shorten these URLs unless the shortener preserves every query parameter and can be trusted long term.

Chrome Web Store documentation guarantees forwarding for `utm_source`, `utm_medium`, and `utm_campaign`. `utm_content` is kept here as a stable internal asset registry, but content-level attribution must be treated as unverified unless it becomes visible in Store reporting. Do not infer an individual asset's installs from `utm_content` alone.

```text

```

Required format:

```text
utm_source={channel}&utm_medium={organic|paid_search}&utm_campaign=30day_growth&utm_content={specific_asset}
```

## Recording convention

Copy source, medium, campaign, and content into the asset-performance log exactly. Keep each value stable for the full campaign so results remain comparable. Website and README values above match the current working files; YouTube, social, directory, release, and paid-search values are reserved until those assets are approved and published.

For decisions, use the three Store-supported dimensions first: source, medium, and campaign. Record content for asset inventory and channel-side metrics, but mark content-level Store results `unverified` until the dashboard proves that dimension is available. Recent Store data remains provisional for at least 48 hours.
