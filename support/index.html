Support

Get help with ChannelFence

YouTube changes often. If a block control is missing or content from a blocked creator appears somewhere unexpected, send enough detail for the problem to be reproduced.

Report a bug on GitHub

For compatibility bugs and feature requests, use the public ChannelFence issue tracker. Check existing issues first so related reports can stay together.

A useful bug report includes:

  • The ChannelFence and Chrome versions you are using.
  • The YouTube surface involved, such as Home, search, Watch Next, a channel page, or Shorts.
  • The steps that caused the problem and what you expected instead.
  • A screenshot when it is safe to share one.
Protect your private information

Do not post account details, private browsing information, or an exported block list in a public issue. ChannelFence does not need your YouTube password or Chrome credentials.

Contact support by email

For a question that should not be public, email support@channelfence.app. Please do not email passwords, authentication codes, or a complete exported block list.

Privacy and source code

ChannelFence is free and open source. You can review the source code on GitHub or read the privacy policy.
