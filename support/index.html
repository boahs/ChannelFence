Support

Get help with ChannelFence

YouTube changes often. If a block control is missing or content from a blocked creator appears somewhere unexpected, send enough detail for the problem to be reproduced.

Find the right guide

  • Block, unblock, and back up your creator list.
  • Hide Shorts from feeds while keeping the viewer available.
  • Hide Home inserts and choose a compact thumbnail size.
  • Choose ChannelFence's interface language.

Using Firefox

ChannelFence supports desktop Firefox 142 or later. Install it from Firefox Add-ons, allow YouTube access if Firefox prompts, and refresh any YouTube tabs that were already open. Firefox for Android has not been validated.

Report a bug on GitHub

For compatibility bugs and feature requests, use the public ChannelFence issue tracker. Check existing issues first so related reports can stay together.

A useful bug report includes:

  • Your ChannelFence version, browser name (Chrome or Firefox), and browser version.
  • The YouTube surface involved, such as Home, search, Watch Next, a channel page, or Shorts.
  • Your ChannelFence language and YouTube language, which can be different.
  • For a feed or layout problem, the hiding options and thumbnail size you selected.
  • The steps that caused the problem and what you expected instead.
  • A screenshot when it is safe to share one.
Protect your private information

Do not post account details, private browsing information, or an exported block list in a public issue. ChannelFence does not need your YouTube password or browser account credentials.

Contact ChannelFence on X

For questions and feedback, contact @GetChannelFence on X.

Privacy and source code

ChannelFence is free and open source. You can review the source code on GitHub or read the privacy policy.
