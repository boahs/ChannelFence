ChannelFence vs. Channel Blocker

Want a creator to stop appearing on YouTube? Both extensions address that problem. ChannelFence combines a saved creator block list with Shorts controls, optional Home cleanup, and public compatibility checks. Channel Blocker also offers regular-expression filtering.

Reviewed November 3, 2026 · ChannelFence 0.2.8 and Channel Blocker 3.0.5

Firefox availability updated November 8, 2026: ChannelFence 0.2.9 is now available for desktop Firefox.

ChannelFence's live YouTube checks run on separate schedules: Chrome twice daily and Firefox daily.

A comparison with a stated perspective

We build ChannelFence, so this page explains why we think it is worth choosing. The comparison uses our source and tests alongside Channel Blocker's official listing and README. It is a documentation review, not a hands-on reliability benchmark of both extensions.

Which Channel Blocker are we comparing?

This is Channel Blocker by timemachine.development. Its listing describes blocking videos, users, channels, and comments, with regular expressions for custom matching. Its official project is open source. It is a separate extension from BlockTube.

Why we would choose ChannelFence

ChannelFence suits a specific request: “I want to keep discovering videos, but stop seeing this creator.” The same saved list applies across supported Home feeds, search results, recommendations, Watch Next, Shorts, playlists, comments, and direct pages.

  1. Use the ChannelFence control beside a supported creator name, or its action in a supported video menu.
  2. Matching content disappears from supported surfaces. Supported direct visits show a blocked-page screen.
  3. Use Undo for a mistake, or open Manage block list to review creators, remove entries, or add a handle manually.

You can pause blocking without deleting the list and export a private backup. Export and Import are for ChannelFence backups. The blocking and backup guide walks through those controls.

If the rest of Home feels crowded, optional cleanup controls hide supported sponsored cards, Explore more topics, game shelves, and promotional inserts. The compact grid offers Small, Medium, and Large thumbnails. These controls start off, and do not skip ads playing inside videos or the Shorts viewer.

YouTube changes. We test for that.

ChannelFence's public live YouTube checks are scheduled twice a day for Chrome and daily for Firefox, alongside regression tests for updates. Live checks cover selected creator controls across all 18 supported interface languages. The changelog records fixes and the coverage added with them.

Our aim is to catch compatibility problems early and patch them before you notice. A failure in a covered workflow can flag a YouTube change without waiting for a user report. Tests cannot catch every layout or account experiment, and releasing a fix still takes time. Public results let you inspect that maintenance work yourself.

When Channel Blocker may fit better

If you specifically want to write matching patterns, Channel Blocker's documented regex support is a reason to consider it. ChannelFence does not provide a regex or keyword-rule editor. Open source and a no-data-collection declaration are strengths shared by both projects, rather than reasons to dismiss either one.

ChannelFence's own privacy policy explains an important detail: it may look up public compact Shorts creator metadata directly from YouTube, without account credentials. Your list and settings stay in local extension storage and are not sent to the developer.
