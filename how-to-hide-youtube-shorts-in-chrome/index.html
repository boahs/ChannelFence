How to hide YouTube Shorts in Chrome

ChannelFence can remove supported Shorts shelves and cards from Home, search, and other feeds without removing the Shorts tab or preventing you from opening the Shorts viewer.

Hide Shorts from YouTube feeds

  1. Install ChannelFence from the Chrome Web Store.
  2. Refresh YouTube if it was already open.
  3. Select the ChannelFence icon in Chrome.
  4. Turn on Hide Shorts in feeds.

The same setting is available on ChannelFence's full settings page. Changes are stored locally and stay synchronized between the popup and settings.

The Shorts tab remains available

This option is meant to make regular feeds less intrusive. It does not remove YouTube's Shorts navigation item or disable the direct Shorts viewer.

Block one Shorts creator instead

If you still use Shorts but do not want to see a specific creator, leave the feed setting off and block only that creator:

  • Use ChannelFence's control on a supported compact Shorts card without opening it.
  • Use the ChannelFence button in the Shorts viewer. After blocking the current creator, ChannelFence advances to the next Short.
  • Open settings and enter the creator's handle or channel URL manually.

Turn Shorts back on

Open the popup or settings and turn off Hide Shorts in feeds. The setting does not delete your creator block list.
