How to block YouTube channels in Chrome

ChannelFence adds a persistent creator block list to YouTube. You can block from a supported video menu, beside a creator name, or by entering a handle or channel URL.

Updated November 8, 2026 · For ChannelFence 0.2.9. These steps use the English labels.

Using desktop Firefox? Install ChannelFence from Firefox Add-ons and open it from Firefox's extensions menu. The blocking and backup controls below work there too.

ChannelFence is free, open source, and privacy-first.
Your block list stays in your browser.

Add to Chrome Add to Firefox

Before you start

  1. Install ChannelFence from the Chrome Web Store.
  2. Refresh any YouTube tabs that were already open.
  3. Open Chrome's Extensions menu and select ChannelFence. Pin it there if you want its icon beside the address bar.

ChannelFence starts enabled with an empty block list. Choose Manage block list at the bottom of its popup whenever you need the full settings page. If your controls use another language, see how to change ChannelFence's language.

Method 1: block beside a creator name

  1. Find the ⊘ control beside a supported creator name.
  2. Select it to add that creator to your block list.
  3. Open the popup to find the creator under Recently blocked.

Matching content is hidden on supported Home feeds, search results, recommendations, Shorts, and playlists. Supported direct visits show a blocked-page screen. Comments are also hidden when ChannelFence can identify the commenter and Hide comments from blocked creators is enabled in settings, which it is by default.

Method 2: use a video's three-dot menu

  1. Open the three-dot menu on a supported video card.
  2. Select ChannelFence: Block.
  3. Select Undo in the confirmation on YouTube if you blocked the wrong creator.

In a supported compact Shorts menu, choose ChannelFence: Block creator to block the creator without opening the Short.

Method 3: enter a handle or channel URL

  1. Open ChannelFence and choose Manage block list.
  2. Under Blocked creators, find Block by handle or channel URL.
  3. Enter a handle such as @example, or paste a YouTube channel URL such as https://www.youtube.com/@example.
  4. Select Block creator and return to YouTube.

Manual entry is helpful when you already know the channel you want to block or cannot find an inline control on a particular YouTube layout.

Block the creator of the current page

Open a YouTube channel, video, or Short, then open the ChannelFence popup. Check the creator shown under Current page and select Block creator. If YouTube identifies multiple creators, the popup lets you choose which one to block. If it says No creator detected, use the creator's handle in settings instead.

What a creator block does not cover

ChannelFence matches the creator identifiers attached to content. A copy or reupload posted by a different channel is separate content and is not automatically blocked.

Undo, unblock, or pause

  • Undo immediately: select Undo in the confirmation that appears after blocking on YouTube.
  • Unblock later: select Unblock under Recently blocked in the popup. For older entries, choose Manage block list, use Search blocked creators, and select Unblock beside the matching entry.
  • Pause: turn off the switch at the top of the popup, or turn off Enable ChannelFence in settings. Your list and preferences are kept for when you enable it again.

Back up your block list or move it to another browser profile

  1. Open Manage block list and select Export in the Blocked creators section.
  2. Keep the downloaded JSON file somewhere you can find it.
  3. To restore it, install ChannelFence in the destination Chrome or desktop Firefox profile, open the same settings page, and choose Import.
  4. Select your exported JSON file. Its creators are merged with the existing block list.

The backup contains blocked creators, not settings such as language or Home layout. ChannelFence stores its list locally and does not automatically sync it between profiles or devices. Share an export only if you want to share the creators it contains.

If a block control is missing

Check that ChannelFence is enabled, then refresh the YouTube tab after installing or updating the extension. Controls depend on the creator information and layout YouTube provides. If a supported surface stops working, the support page explains what to include in a bug report.
